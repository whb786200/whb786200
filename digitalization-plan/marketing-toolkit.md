- `销冠不愿说的秘密：不是更努力，而是用AI“开单到手软”`
- `客户来了三次，说再看看。我用AI把逼单话术全包了`

- `客户说“考虑一下”，销冠的3个AI回复`
- `客户说“太贵了”，销冠的3个AI回复`
- `干了10年销售，离职时你带走什么？`

客户分层：

| 层级 | 典型状态 | 跟进重点 |
|------|----------|----------|
| A类 | 预算匹配、家庭意见基本统一、近期可决策 | 解决最后顾虑，推动复访/认购 |
| B类 | 有兴趣但还在比较 | 补充信息，制造对比优势 |
| C类 | 预算或需求不清晰 | 重新诊断需求，避免硬推 |
| 流失类 | 久未回复或明确暂缓 | 节点触达，保持低频价值输出 |

异议处理提示词：

```text
你是一名有7年经验的地产销冠。
客户画像：[家庭结构/预算/关注点/到访次数/主要顾虑]
客户原话：[太贵了/考虑一下/再看看/节假日不看房]
请输出3种回复：
1. 理性型客户：补充信息和对比逻辑
2. 感性型客户：理解情绪并降低压力
3. 犹豫型客户：拆解顾虑并推动下一步
要求：真诚、短句、适合微信发送，不夸大承诺。
```

## 4. AI视频获客流程

适用文章：

- `如何用AI做房产视频获客？从0到1搭建你的获客系统`
- `地产人还在手摇式拍视频？即梦AI帮你一天发五条`
- `AI房产视频提示词终极指南：Seedance 2.0从入门到精通`
- `房产AI视频只能做15秒？五步教你做出60秒长视频`
- `为什么你的视频没人看？底层原因是什么？`

核心原则：

| 误区 | 正确做法 |
|------|----------|
| 为了发视频而发视频 | 每条视频回答一个客户问题 |
| 只展示房子 | 展示客户能得到什么 |
| 只追求炫酷画面 | 前3秒钩子 + 清楚卖点 + 明确转化动作 |
| 视频生成完就结束 | 必须接私信、表单、电话、复访 |

六步法：

1. 选一个客户问题。
2. 找一个项目卖点回答它。
3. 写前3秒钩子和60秒脚本。
4. 生成分镜和视频素材。
5. 发布到目标平台。
6. 记录线索和转化。

## 7. 合规边界

1. 不使用未授权的人脸、声音、直播间画面做商业发布。
2. AI生成视频必须人工审核，避免虚假交付、虚假景观、虚假采光承诺。
3. 客户案例必须脱敏，不发布手机号、聊天截图、个人隐私。
4. 价格、政策、优惠以项目官方口径为准。
5. AI话术只能辅助销售，不替代真实沟通和合规承诺。
