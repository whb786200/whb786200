# 试验工程师智能平台操作说明书

## 1. 登录

打开系统后访问：

```text
http://localhost:3001/
```

默认管理员：

```text
用户名：admin
密码：admin123
```

普通用户可从注册入口创建账号。

## 2. 注册人员入口

注册时填写：

- 用户名
- 姓名
- 单位
- 证书编号
- 手机号
- 推广码

未填写推广码时，用户按普通注册获得初始积分。填写他人推广码时，新用户和推荐人都会获得对应积分。

## 3. 积分管理

系统内置积分规则：

- 自然注册：赠送初始积分。
- 使用推广码注册：新用户获得奖励积分，推荐人获得推广积分。
- 下载资源：按资源类型扣减积分。
- 管理员可在人员管理中手动调整积分。

## 4. 表格资源库

资源库已导入工程质量检测常用 Excel 计算表格，可按关键词检索、分类查看和下载。

建议用法：

1. 在搜索框输入试验名称或材料名称。
2. 查看资源分类和积分消耗。
3. 积分足够时点击下载。

## 5. 自动计算工作台

系统包含常用试验计算工具，例如：

- 筛分级配
- 含水率
- 干密度
- 压实度
- 液塑限
- 混凝土性能轻量估算

输入检测数据后，系统自动输出计算结果和判定参考。

## 6. 试验工程师智能体

智能体用于辅助推荐：

- 应使用哪些表格。
- 可参考哪些资料。
- 哪类开源项目适合融合。
- 常见检测数据如何初步计算。

它是本地规则型助手，不替代正式规范、检测报告和持证人员审核。

## 7. 资料库

资料库索引来自工程检测相关资料合集，支持按文件名、类别和关键词查找，方便后期快速调用。

## 8. 开源项目融合清单

系统展示已整理的国外/国内开源项目，按领域分为：

- 勘察
- 土工试验
- 岩土分析
- 实验室管理
- 检验试验管理
- 自动化测试框架

桌面一键包默认只带运行索引。完整开源源码在 GitHub 大仓：

```text
https://github.com/whb786200/whb786200/tree/main/projects/test-engineer-platform
```

## 9. 常见问题

### 页面打不开

确认黑色启动窗口没有关闭，然后访问：

```text
http://localhost:3001/
```

### 双击后闪退

优先使用带 `runtime/node` 的完整一键安装包。若仍失败，右键 `一键启动.bat`，选择“在终端中运行”，查看错误信息。

### 数据如何迁移

复制整个安装文件夹，尤其是 `data/` 文件夹。
