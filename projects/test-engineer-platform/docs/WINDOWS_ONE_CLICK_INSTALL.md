# Windows 一键安装和启动说明

适用对象：不会配置 Node.js、不会使用命令行的普通用户。

## 最简单用法

1. 解压桌面压缩包 `试验工程师智能平台-一键安装包.zip`。
2. 进入解压后的文件夹。
3. 双击 `一键启动.bat`。
4. 浏览器会自动打开：

```text
http://localhost:3001/
```

默认管理员账号：

```text
用户名：admin
密码：admin123
```

## 如果浏览器没有自动打开

手动复制下面地址到浏览器：

```text
http://localhost:3001/
```

## 如果提示端口占用

说明本机已有程序占用了 `3001` 端口。先关闭旧窗口，或重启电脑后再双击 `一键启动.bat`。

## 如果 Windows 弹出安全提示

选择“仍要运行”。本包是本地 Node.js 服务，不会自动上传你的数据。

## 数据保存在哪里

运行数据在安装目录的 `data/` 文件夹中：

- `data/db.json`：用户、积分、注册和推广记录。
- `data/resources.json`：Excel 表格资源索引。
- `data/knowledge-resources.json`：资料库索引。

备份时直接复制整个安装文件夹即可。

## 发给别人怎么用

把桌面上的 `试验工程师智能平台-一键安装包.zip` 发给对方。对方解压后双击 `一键启动.bat` 即可。

## 开发者方式

如果对方已经安装 Node.js 20+，也可以在源码目录执行：

```powershell
npm install
npm start
```

访问：

```text
http://localhost:3001/
```
